## 1️⃣ 技术架构设计

### 1.1 SSR 实现方式

**选择**: 自定义 SSR 框架（基于 Cloudflare Workers）

**原因**:
- ✅ 与 Cloudflare 生态深度整合
- ✅ 轻量级，无 Next.js/Nuxt.js 重量级框架
- ✅ 完全控制渲染逻辑
- ✅ 适合 Workers 无服务器环境

**架构**:
```typescript
// SSR Worker 入口
export default {
  async fetch(request: Request, env: Env, ctx: ExecutionContext) {
    const url = new URL(request.url);
    
    // 1. 检查是否是 API 请求
    if (url.pathname.startsWith('/api/')) {
      return handleApi(request, env);
    }
    
    // 2. SSR 渲染页面
    const html = await renderPage(request, env);
    
    // 3. 注入客户端水合脚本
    return new Response(html, {
      headers: {
        'Content-Type': 'text/html',
        'Cache-Control': 'public, max-age=300', // 5 分钟 CDN 缓存
      },
    });
  },
};
```

**SSR 页面结构**:
```
SSR HTML
├── 静态内容（服务器渲染）
│   ├── Header
│   ├── Layout
│   └── 初始数据（从 DO 缓存读取）
│
└── 客户端水合
    ├── React 组件加载
    ├── 事件绑定
    └── 实时更新订阅（WebSocket/SSE）
```

### 1.2 动态智能缓存策略

**核心组件**: Durable Objects (DO)

#### 缓存触发条件

| 触发类型 | 触发条件 | 处理方式 |
|---------|---------|---------|
| **Analytics Engine 写入** | 新点击/转化事件 | AE 自动触发 Worker → 写入 DO |
| **API 数据更新** | 后台管理系统更新 | 直接写入 DO + 失效通知 |
| **定时清理** | 数据过期（7 天） | DO Alarm 定时触发清理 |
| **手动失效** | 管理员操作 | API 调用 → 清除指定缓存 |

#### 缓存失效机制

```typescript
// 1. 时间失效（TTL）
interface CacheMetadata {
  createdAt: number;      // 创建时间
  expiresAt: number;      // 过期时间（7 天）
  lastAccessed: number;   // 最后访问时间
}

// 2. 事件失效
async function invalidateCache(event: CacheInvalidationEvent) {
  const cacheDO = env.CACHE_DO.get(event.cacheId);
  
  switch (event.type) {
    case 'PURGE_ALL':
      await cacheDO.purgeAll();
      break;
    case 'PURGE_BY_KEY':
      await cacheDO.delete(event.key);
      break;
    case 'REFRESH':
      await cacheDO.refresh(event.key);
      break;
  }
}

// 3. 版本失效（缓存键带版本号）
const cacheKey = `data:v2:${businessKey}`; // v2 变更时清空 v1
```

#### 缓存更新策略

**策略**: 增量追加 + 定期清理

```typescript
export class CacheDurableObject {
  // 增量追加（核心）
  async appendClicks(newClicks: ClickData[]) {
    await this.ctx.storage.transaction(async (tx) => {
      // 1. 读取现有数据
      const existing = await tx.sql`SELECT * FROM clicks`;
      
      // 2. 追加新数据
      await tx.sql`INSERT INTO clicks VALUES ${newClicks}`;
      
      // 3. 清理过期数据（>7 天）
      const sevenDaysAgo = Date.now() - (7 * 24 * 60 * 60 * 1000);
      await tx.sql`DELETE FROM clicks WHERE timestamp < ${sevenDaysAgo}`;
    });
  }
  
  // 批量读取（优化）
  async getClicks(limit: number = 1000): Promise<ClickData[]> {
    const result = await this.ctx.storage.sql`
      SELECT * FROM clicks 
      ORDER BY timestamp DESC 
      LIMIT ${limit}
    `;
    return result.toArray();
  }
}
```

                  │

┌─────────────────────────────────────────────────────────┐

│  ┌─────────────────────────────────────────────────┐    │
│  │  5. 解析 HTML，显示首屏                          │    │
│  │     - FCP: < 0.9s                               │    │
│  │                                                  │    │
│  │  6. 下载并执行 JS，激活水合                      │    │
│  │     - TTI: < 1.5s                               │    │

│  │  7. 建立实时更新连接（WebSocket/SSE）            │    │

│  └─────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────┘

同时：
┌─────────────────────────────────────────────────────────┐
│         Analytics Engine (自动触发)                       │
│  ┌─────────────────────────────────────────────────┐    │
│  │  8. 检测到新点击                                 │    │
│  │                                                  │    │
│  │  9. 自动触发 Worker → 写入 DO                    │    │
│  │     await cacheDO.appendClicks(newClicks)       │    │
│  │                                                  │    │
│  │  10. 推送通知到客户端（WebSocket/SSE）           │    │
│  └─────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────┘
```

#### 数据流

```
1. SSR 渲染时：
   Worker → DO 读取缓存 → 渲染 HTML → 返回

2. 客户端水合后：
   浏览器 → WebSocket 连接 → 接收实时更新

3. 新点击产生时：
   Analytics Engine → AE 触发器 → DO 追加数据 → WebSocket 推送 → 客户端更新
```

  await syncFromAE();

// 2. 发送告警
await sendAlert('AE 触发器失效，已切换定时同步');
```
