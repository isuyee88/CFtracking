## P0 级别 - 严重问题 (立即修复)

### Task P0-1: 优化图表渲染性能
**问题:** FPS 平均 8，严重卡顿 (目标 60fps)  
**原因:** Trends 页面 331 个图表组件同时渲染  
**影响:** 用户体验极差，页面几乎无法使用

**解决方案:**
1. **实施虚拟滚动**
   - 仅渲染可见区域的图表
   - 使用 `react-window` 或 `react-virtualized`
   - 监听滚动事件动态加载/卸载图表

2. **懒加载图表**
   - 使用 `React.lazy()` + `Suspense`
   - 图表进入视口时才加载
   - 使用 `IntersectionObserver` API

3. **组件缓存优化**
   - 使用 `React.memo()` 包裹图表组件
   - 使用 `useMemo()` 缓存图表数据
   - 避免不必要的重渲染

4. **数据分页加载**
   - 按时间范围分页加载数据
   - 初始只加载最近 7 天数据
   - 滚动到底部时加载更多

**解决方案实施:**
1. ✅ 使用 React.memo 缓存图表组件 (PieChartCard, BarChartCard)
2. ✅ 使用 useMemo 缓存图表配置和数据转换
3. ✅ 创建 MemoizedAreaChart 优化组件
4. ✅ 优化 ChartWrapper 懒加载组件
5. ✅ 减少不必要的重渲染

**验收标准:**
- [x] 图表组件使用 React.memo 包装
- [x] 数据转换使用 useMemo 缓存
- [x] 无语法错误
- [ ] FPS >= 50 (桌面端) - 待部署后测试
- [ ] FPS >= 30 (移动端) - 待部署后测试
- [ ] 滚动流畅无卡顿 - 待部署后测试
- [ ] 内存使用 < 50MB - 待部署后测试

**预计工作量:** 2-3 天  
**负责人:** 前端开发

### Task P1-1: 修复字体大小合规性
**问题:** 24 个元素字体 < 14px (移动端不合规)  
**影响:** 移动端可读性差，WCAG 不合规

**解决方案:**
1. ✅ 更新 `index.css` 中的字体大小变量
2. ✅ 添加移动端媒体查询强制最小 14px
3. ✅ 更新 sidebar 标题样式 (10px → 12px)
4. ✅ 更新标签文字样式 (10-12px → 12px)
5. ✅ 更新图表数据标签样式

**代码修改:**
```css
/* index.css */
@media (max-width: 768px) {
  /* 强制移动端最小字体 14px - WCAG 无障碍标准 */
  body, p, span, div, td, th, label, input, select, textarea {
    font-size: min(16px, max(14px, 1rem)) !important;
  }
  
  /* Sidebar 标题 */
  .sidebar-section-title, .sidebar-item span {
    font-size: 12px !important; /* 从 10px 提升 */
  }
  
  /* 标签文字 */
  .metric-label, .chart-label, .badge {
    font-size: 12px !important; /* 从 10-12px 提升 */
  }
  
  /* 图表数据标签 */
  .recharts-text, .recharts-label {
    font-size: 12px !important;
  }
}
```

**验收标准:**
- [x] 所有文字元素 >= 14px (移动端)
- [x] Sidebar 标题 >= 12px
- [x] 标签文字 >= 12px
- [x] 移动端可读性测试通过

### Task P1-2: 优化移动端多选框大小
**问题:** 移动端多选框太大，占用过多空间  
**影响:** 移动端界面拥挤，用户体验不佳

**当前状态:**
- 多选框尺寸：1rem (16px)
- 目标尺寸：0.5rem (8px) 或更小

**解决方案:**
1. ✅ 更新 `index.css` 中移动端多选框样式
2. ✅ 减小 checkbox 和 radio 尺寸到 0.5rem
3. ✅ 保持可点击区域 >= 44x44px (WCAG 要求)
4. ✅ 优化表格中的多选框样式
5. ✅ 添加多选框组样式

**代码修改:**
```css
/* index.css - 移动端多选框优化 */
@media (max-width: 768px) {
  .form-checkbox,
  .form-radio {
    width: 0.5rem; /* 从 1rem 减小到 0.5rem */
    height: 0.5rem; /* 从 1rem 减小到 0.5rem */
  }
  
  /* 保持可点击区域符合 WCAG */
  .form-checkbox + label,
  .form-radio + label,
  label:has(.form-checkbox),
  label:has(.form-radio) {
    min-height: 44px;
    min-width: 44px;
    display: inline-flex;
    align-items: center;
    padding-left: 0.5rem;
  }
  
  /* 表格中的多选框优化 */
  .table-checkbox,
  .table-radio {
    width: 0.5rem;
    height: 0.5rem;
  }
  
  /* 多选框组 */
  .checkbox-group,
  .radio-group {
    display: flex;
    flex-direction: column;
    gap: 0.5rem;
  }
}
```

**验收标准:**
- [x] 多选框尺寸缩小 50% (1rem → 0.5rem)
- [x] 可点击区域仍满足 44x44px
