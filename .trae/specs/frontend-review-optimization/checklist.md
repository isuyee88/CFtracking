# Checklist - 前端评审与优化计划

## 字体系统评审
- [ ] 字体加载时间 < 1s
- [ ] 无 FOUT/FOIT 问题
- [ ] 移动端字体大小 >= 14px
- [ ] 标题字体层级清晰 (h1-h6)
- [ ] 中文字体渲染正常
- [ ] 字体粗细符合设计规范
- [ ] 字间距和行高可读性好

## 触发界面评审
- [ ] 所有按钮最小尺寸 44x44px
- [ ] 按钮 hover 状态明显
- [ ] 按钮 active 状态有反馈 (scale 0.97)
- [ ] 按钮 focus 状态可见 (2px outline)
- [ ] 图标按钮易于识别
- [ ] 表单输入聚焦效果明显 (左侧高亮边框)
- [ ] 表格滚动渐变阴影提示正常
- [ ] 手势提示动画流畅 (仅首次显示 3 次)

## 视图布局评审
- [ ] 375px 宽度布局正常
- [ ] 768px 宽度布局正常
- [ ] 1024px 宽度布局正常
- [ ] 移动端底部导航可横向滚动
- [ ] 侧边栏展开/收起动画流畅
- [ ] 内容区域 padding 适配移动端
- [ ] Safe area 适配正常 (notched devices)
- [ ] 平板布局合理

## 表格系统评审
