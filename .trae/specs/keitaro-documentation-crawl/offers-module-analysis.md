# Offers 模块详细分析

## 1. 模块概述

Offers模块是Keitaro的重要功能模块，用于管理优惠（Offers）和着陆页（Landing Pages）。该模块提供了完整的优惠和着陆页生命周期管理，从创建到监控再到优化的全过程。

**主要职责**：
- 优惠的创建和管理
- 着陆页的配置和管理
- 多优惠管理（Multioffers）
- 转化跟踪和优化
- 着陆页编辑器和JS适配器

## 2. 核心功能

### 2.1 优惠管理

**功能描述**：允许用户创建、编辑和管理优惠，设置基本参数和配置选项。

**配置选项**：
- **Main settings**：
  - Offer name：优惠名称
  - Group：优惠分组
  - Affiliate network：联盟网络
  - Local：本地优惠
  - Redirect：重定向优惠
  - URL：优惠链接

- **Settings**：
  - Countries：目标国家
  - Payout type：支付类型
  - Payout：支付金额
  - Allow upsells (rebills)：允许追加销售
  - Conversion cap：转化上限

- **Values**：自定义值
- **Notes**：备注信息

### 2.2 着陆页管理

**功能描述**：允许用户创建和管理不同类型的着陆页。

**着陆页类型**：
- **Local**：本地着陆页（存储在服务器上）
- **Redirect**：重定向着陆页（跳转到外部链接）
- **Preload**：预加载着陆页
- **Action**：动作着陆页（执行特定动作）

**配置选项**：
- 着陆页名称和分组
- 着陆页类型选择
- URL设置
- 高级选项（如缓存控制）

### 2.3 多优惠管理

**功能描述**：通过Multioffers功能，用户可以创建包含多个优惠的组合。

**主要特性**：
- 批量添加优惠
- 智能分配逻辑
- 基于条件的优惠选择
- 实时监控和调整

### 2.4 着陆页编辑器

**功能描述**：提供内置的着陆页编辑器，用于创建和修改着陆页内容。

**编辑器功能**：
- 所见即所得编辑
- 模板支持
- 代码编辑模式
- 预览功能

### 2.5 JS适配器

**功能描述**：提供JavaScript适配器，用于在着陆页中集成跟踪代码。

**适配器功能**：
- 简化跟踪代码集成
- 支持动态参数传递
- 提供事件跟踪
- 兼容各种着陆页平台

### 2.6 优惠和着陆页报告

**功能描述**：提供详细的优惠和着陆页性能报告。

**报告功能**：
- 实时数据更新
- 多维度数据展示
- 自定义时间区间
- 数据导出功能
- 图表和表格视图

### 6.2 关键API接口

**Offer API**：
- GET /api/offers - 获取优惠列表
- POST /api/offers - 创建新优惠
- GET /api/offers/{id} - 获取优惠详情
- PUT /api/offers/{id} - 更新优惠
- DELETE /api/offers/{id} - 删除优惠

**Landing Page API**：
- GET /api/landing-pages - 获取着陆页列表
- POST /api/landing-pages - 创建新着陆页
- GET /api/landing-pages/{id} - 获取着陆页详情
- PUT /api/landing-pages/{id} - 更新着陆页
- DELETE /api/landing-pages/{id} - 删除着陆页

**Tracking API**：
- GET /lp - 处理着陆页访问
- POST /lp/convert - 处理着陆页转化
