# Traffic Sources 模块详细分析

## 1. 模块概述

Traffic Sources模块是Keitaro的重要功能模块，用于管理流量来源。该模块提供了完整的流量来源生命周期管理，从创建到监控再到优化的全过程。

**主要职责**：
- 流量来源的创建和管理
- 流量参数传递和管理
- 流量来源S2S回传
- 流量来源性能报告
- 第三方流量来源集成

## 2. 核心功能

### 2.1 流量来源管理

**功能描述**：允许用户创建、编辑和管理流量来源，设置基本参数和配置选项。

**配置选项**：
- **基本信息**：流量来源名称、分组、状态等
- **参数设置**：流量来源参数映射和传递
- **S2S回传**：服务器到服务器回传配置
- **模板选择**：使用预设的流量来源模板
- **自定义设置**：根据需要进行自定义配置

### 2.2 流量参数传递

**功能描述**：通过Passing traffic source parameters功能，用户可以设置如何传递和处理流量来源参数。

**参数处理**：
- 参数映射：将流量来源参数映射到系统参数
- 参数传递：将参数传递到着陆页和优惠
- 参数转换：对参数进行转换和处理
- 参数验证：验证参数的有效性

### 2.3 流量来源S2S回传

**功能描述**：通过Traffic source S2S postback功能，用户可以设置流量来源的服务器到服务器回传。

**回传配置**：
- 回传URL设置
- 回传参数配置
- 回传触发条件
- 回传测试功能

### 2.4 流量来源报告

**功能描述**：提供详细的流量来源性能报告，支持多维度数据统计和分析。

**报告功能**：
- 实时数据更新
- 多维度数据展示
- 自定义时间区间
- 数据导出功能
- 图表和表格视图
- 对比分析

### 2.5 第三方流量来源集成

**功能描述**：支持与各种第三方流量来源的集成，如HasOffers等。

**集成功能**：
- 预设模板：提供常见流量来源的预设模板
- API集成：通过API与流量来源平台集成
- 数据同步：同步流量来源数据
- 自动优化：基于流量来源数据进行优化

### 6.2 关键API接口

**Traffic Source API**：
- GET /api/traffic-sources - 获取流量来源列表
- POST /api/traffic-sources - 创建新流量来源
- GET /api/traffic-sources/{id} - 获取流量来源详情
- PUT /api/traffic-sources/{id} - 更新流量来源
- DELETE /api/traffic-sources/{id} - 删除流量来源

**Template API**：
- GET /api/traffic-source-templates - 获取流量来源模板列表
- GET /api/traffic-source-templates/{id} - 获取模板详情

**Postback API**：
- POST /api/traffic-sources/{id}/postback - 测试流量来源回传
