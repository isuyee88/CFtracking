# Campaign 模块详细分析

## 1. 模块概述

Campaign模块是Keitaro的核心功能模块，用于创建、管理和优化广告系列。该模块提供了完整的广告系列生命周期管理，从创建到监控再到优化的全过程。

**主要职责**：
- 广告系列的创建和配置
- 流量分配和流程管理
- 转化跟踪和性能分析
- 多维度数据统计和报告
- A/B测试和流量分割

## 2. 核心功能

### 2.1 广告系列创建

**功能描述**：允许用户创建新的广告系列，设置基本参数和配置选项。

**配置选项**：
- **General**：广告系列名称、描述、状态等基本信息
- **Domain**：选择使用的域名
- **Alias**：广告系列别名
- **Group**：广告系列分组
- **Source**：流量来源
- **Flow rotation**：流量分配方式（基于位置或权重）
- **Bind visitors**：访问者绑定设置
- **Cost model**：成本模型设置
- **Traffic Loss**：流量损失百分比
- **Uniqueness**：唯一性设置
- **Uniqueness TTL**：唯一性时间窗口
- **Bypass cache**：缓存绕过设置
- **API token**：API访问令牌
- **Status**：广告系列状态（启用/禁用）

### 2.2 流量流程管理

**功能描述**：通过Flows功能，用户可以创建和管理复杂的流量分配流程。

**主要特性**：
- 可视化流程编辑器
- 多路径流量分配
- 条件分支和过滤
- 流量权重设置
- 实时监控和调整

### 2.3 流量过滤

**功能描述**：通过Filters功能，用户可以设置各种条件来过滤流量。

**过滤条件**：
- GEO定位
- 设备类型
- 浏览器
- 操作系统
- 语言
- IP地址
- 时间和日期
- 自定义参数

### 2.4 广告系列报告

**功能描述**：提供详细的广告系列性能报告，支持多维度数据统计和分析。

**报告功能**：
- 实时数据更新
- 多维度数据展示
- 自定义时间区间
- 数据导出功能
- 图表和表格视图
- 对比分析

### 2.5 转化跟踪

**功能描述**：通过S2S postbacks和其他跟踪方法，实现准确的转化跟踪。

**跟踪方式**：
- S2S postbacks
- Pixel跟踪
- API跟踪
- 第三方像素集成（如FB Pixel、TikTok Pixel）

### 2.6 A/B测试

**功能描述**：支持着陆页和优惠的A/B测试，优化转化效果。

**测试功能**：
- 多变量测试
- 流量分割
- 统计显著性分析
- 自动优化

## 3. 页面结构

### 3.1 Campaign Report 页面

**页面结构**：

2. **Actions**：操作按钮
   - 批量操作
   - 导出数据
   - 自定义视图

3. **Statistics Table**：统计表格

### 3.2 Creating Campaign 页面

**页面结构**：
1. **Campaign Settings**：广告系列设置

## 4. 技术实现

### 4.1 流量分配算法

**基于位置的分配**：
- 按顺序分配流量
- 适合简单的A/B测试
- 实现简单，易于理解

**基于权重的分配**：
- 按权重比例分配流量
- 支持复杂的流量分配策略
- 更灵活的测试场景

### 4.2 跟踪技术

**S2S Postbacks**：
- 服务器到服务器的直接通信
- 更可靠的跟踪方式

**Pixel跟踪**：
- 客户端跟踪
- 易于集成
- 适合简单的转化场景

**API跟踪**：
- 程序化跟踪
- 高度自定义
- 适合复杂的集成场景

### 4.3 数据存储和分析

**数据存储**：
- ClickHouse数据库
- 高性能数据存储
- 支持大规模数据

**数据分析**：
- 实时数据处理
- 多维度数据分析
- 自定义报告生成

### 6.2 关键API接口

**Campaign API**：
- GET /api/campaigns - 获取广告系列列表
- POST /api/campaigns - 创建新广告系列
- GET /api/campaigns/{id} - 获取广告系列详情
- PUT /api/campaigns/{id} - 更新广告系列
- DELETE /api/campaigns/{id} - 删除广告系列

**Flow API**：
- GET /api/flows - 获取流量流程列表
- POST /api/flows - 创建新流量流程
- PUT /api/flows/{id} - 更新流量流程

**Tracking API**：
- GET /click - 处理点击跟踪
- POST /postback - 处理转化回传
