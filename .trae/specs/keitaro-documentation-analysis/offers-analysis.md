# Keitaro Offers 模块分析报告

## 1. 功能概述
Offers 模块是 Keitaro 广告追踪平台的核心功能之一，用于管理广告 Offer（广告主提供的产品或服务），包括创建、配置和管理 Offer。

## 2. 主要功能

### 2.1 核心功能
- **创建新的 Offer**：允许用户创建新的广告 Offer
- **管理 Offer 分组**：对现有 Offer 进行分组管理
- **联盟网络关联**：选择关联的联盟网络，自动添加必要的标签到 Offer URL
- **本地 Offer 支持**：支持上传 ZIP 归档文件作为本地 Offer，无需重定向
- **重定向类型选择**：选择切换到 Offer 的重定向类型
- **URL 配置**：输入自己的 Offer 地址或从联盟网络获取的地址
- **国家设置**：选择相关国家作为备注，帮助快速选择合适的 Offer
- **支付类型设置**：设置 CPA 或 CPC 支付类型
- **支付金额设置**：指定固定支付金额或选择自动从 postback 获取
- **追加销售支持**：允许 upsells (rebills)，增加收入而不增加转化次数
- **转化上限设置**：设置每日转化限制
- **多 Offer 值支持**：支持多 Offer 值配置
- **备注功能**：为 Offer 添加文本备注

### 2.2 业务逻辑
1. **重定向处理**：根据选择的重定向类型处理流量到 Offer 的跳转
2. **追踪参数传递**：确保追踪参数正确传递，特别是 tid 参数用于唯一标识转化
3. **支付计算**：根据设置的支付类型和金额计算收入
4. **转化处理**：处理从联盟网络收到的 postback，记录转化
5. **追加销售处理**：处理重复的 postback，支持 upsells
6. **转化上限控制**：当达到每日转化上限时，停止向该 Offer 发送流量

## 3. 配置选项

### 3.1 基本配置
- **Offer 名称**：标识 Offer 的唯一名称
- **分组**：所属的 Offer 分组
- **联盟网络**：关联的联盟网络，自动添加必要的标签
- **本地 Offer**：是否为本地 Offer，可上传 ZIP 归档文件
- **重定向类型**：选择重定向类型（如 HTTP 302、JS 重定向、双重重定向等）
- **URL**：Offer 的访问地址

### 3.2 高级配置
- **国家**：选择相关国家作为备注
- **支付类型**：CPA（按转化付费）或 CPC（按点击付费）
- **支付金额**：固定金额或自动从 postback 获取
- **允许追加销售**：是否允许 upsells (rebills)
- **转化上限**：每日转化限制
- **多 Offer 值**：多 Offer 值配置
- **备注**：Offer 的文本备注

## 4. 重定向类型
根据之前的讨论，Keitaro 支持以下重定向类型：
- **HTTP 302 重定向**：标准的 HTTP 重定向
- **JS 重定向**：使用 JavaScript 进行重定向
- **双重重定向**：使用双重重定向方式
- **Meta 重定向**：使用 HTML Meta 标签进行重定向
- **JS 空白引用重定向**：使用 JavaScript 进行重定向，同时清除引用信息
- **远程重定向**：使用远程服务器进行重定向

## 5. 与其他模块的关系
- **与 Campaign 模块**：Offer 被 Campaign 引用，接收来自 Campaign 的流量
- **与 Flow 模块**：Flow 定义流量分配规则，决定哪些流量流向哪些 Offer
- **与 Reports 模块**：Offer 数据在 Reports 模块中进行详细分析
- **与联盟网络**：通过联盟网络关联，自动添加必要的追踪标签

## 6. 最佳实践
- **清晰的命名规范**：使用描述性名称，便于识别和管理
- **合理的分组**：根据业务需求和产品类型进行分组
- **正确的重定向类型**：根据不同的场景选择合适的重定向类型
- **完整的追踪参数**：确保所有必要的追踪参数都正确配置
- **定期监控**：定期查看 Offer 性能，及时调整策略
- **合理的转化上限**：根据联盟网络的限制和自身需求设置转化上限

- 与 Flow 的关联
